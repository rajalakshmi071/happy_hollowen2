# Scary Game

A short, creepy text adventure. Open `index.html` in a browser to play, or visit the GitHub Pages link once published.

## Publishing with GitHub Pages

1. Go to **Settings > Pages**.
2. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
3. Your game will be live at `https://YOUR-USERNAME.github.io/scary-game/`.
